## 🎯 Initial Setup (First Time Only)

### Step 1: Create Your Admin Account

1. **Go to the admin login page:**
   - Navigate to: `yourdomain.com/admin/login`
   - Or click "Admin Login" in the website footer

2. **Create your account:**
   - Click "Don't have an account? Sign up"
   - Enter your details:
     - **Full Name**: Your name
     - **Email**: Your admin email (use a secure one!)
     - **Password**: Create a strong password (min 6 characters)
   - Click "Create Account"

3. **You'll be automatically logged in** and redirected to the admin dashboard

---

### Step 2: Initialize the CMS Database

**IMPORTANT:** Do this immediately after creating your account!

1. Once logged into the admin panel
2. Look for the **"Initialize CMS"** button in the top-right corner
3. Click it
4. Wait for confirmation: "CMS initialized with default content"
5. The page will reload with all your current website content

**What this does:**
- Loads all existing pages into the database
- Sets up the content structure
- Makes everything ready for editing

## 🆘 Common First-Time Questions

**Q: Can I have multiple admin users?**
A: Yes! Just create additional accounts through the signup page. Each user gets full access.

**Q: Will my changes go live immediately?**
A: Yes! All changes are saved to the database and appear on the website instantly.

**Q: Can I undo changes?**
A: Currently, no undo feature. Future updates will include version history. Be careful when editing!

**Q: What if I break something?**
A: Don't worry! Your developer can restore from backups. But it's hard to "break" things - the CMS only edits content, not code.

**Q: Do I need to know HTML or coding?**
A: No! The CMS is designed for non-technical users. Just type and save!
